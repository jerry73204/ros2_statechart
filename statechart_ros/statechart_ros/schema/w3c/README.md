# W3C SCXML 1.0 schema

The XML Schema for SCXML 1.0 from <https://www.w3.org/2011/04/SCXML/> and the
XML namespace schema from <https://www.w3.org/2001/xml.xsd>, as published,
with one change: `scxml.xsd` and `scxml-attribs.xsd` import `xml.xsd` from
this directory instead of from the network, so validation works offline.
